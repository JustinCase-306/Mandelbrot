## What is it?

The Mandelbrot set is one of the most famous structures in mathematics and a textbook example of a fractal. It is a mathematical set of points in the complex number plane that is generated by a surprisingly simple formula, yet it contains an infinitely complex and self-similar boundary.
It is named after the mathematician Benoît Mandelbrot, who visualized it using computer graphics at IBM in 1980, bringing fractals into the public eye.

The Mathematical Idea

To determine if a specific complex number c belongs to the Mandelbrot set, you use a simple recurring calculation (an iteration) with the following formula:
z<sub>n+1</sub> = z<sub>n</sub><sup>2</sup> + c


You always start with the initial value z₀ = 0. You plug this into the formula along with your chosen number c to calculate z₁. Then, you feed that result back into the formula to find z₂, and so on.
As you repeat this infinitely, only one of two things can happen:
1. The values stay bounded: The sequence never escapes into infinity (the absolute value of z never exceeds 2). If the numbers stay trapped forever, the number c belongs to the Mandelbrot set (traditionally colored black in visualizations).
2. The values explode: The sequence grows rapidly toward infinity. If this happens, the point does not belong to the set.
